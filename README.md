# 单向个人记忆（Directional Memory）

适用于 AstrBot 4.29.3+ 的独立插件，通过代码限制记忆读取方向，而不是依靠提示词要求模型保密。

| 当前请求 | 同一人的私聊记录 | 同一人在当前群的记录 | 同一人在其他群的记录 | 其他人的记录 |
| --- | --- | --- | --- | --- |
| 本人私聊 | 可读 | 可读 | 可读 | 不可读 |
| 本人群聊 | 不可读 | 可读 | 不可读 | 不可读 |

每条记录都带有平台、机器人账号、真实用户 ID、来源群和时间。昵称、消息内自称、引用内容不能改变身份。群聊缺少可靠群号时直接跳过，不会降级为私聊权限。

## 功能范围

- 被动保存实际用户自己的直接文字；不记录机器人回复、转发内容、引用原文或图片。
- 本地 SQLite 持久化，中文字符/双字和英文词匹配，结合手动备注与近期记录召回。
- 临时追加到 `extra_user_content_parts`，不改写系统提示词或会话历史。
- 不主动发消息，不调用聊天、摘要、Embedding 或外部记忆 API。
- 读取与删除复用同一套可见范围规则；没有指定他人 QQ 或任意群号的查询入口。
- 自动记录、命令和召回均执行用户启用名单。
- 被动过滤器始终不通过唤醒检查，不改变群聊唤醒状态；采集遵守白名单、会话总开关和会话插件开关，召回也检查会话开关。

本插件提供的是有来源的文字记忆与显式备注，不是自动事实抽取、向量语义检索或无限聊天档案。它从启用后开始积累；每次按相关性、时间、条数和字符预算选取记录，不会把所有群的全部原文一次性塞给模型。

## 安装

本仓库中插件位于 `plugins/astrbot_plugin_directional_memory/`。把整个目录复制到 AstrBot 的 `data/plugins/`，目录中应直接包含 `metadata.yaml`、`main.py`、`store.py` 和 `_conf_schema.json`，然后在 WebUI 重载插件或重启 AstrBot。

也可以把上述目录内容打包成 ZIP（文件在压缩包根目录），通过 AstrBot 的本地插件上传入口安装。仓库根目录不是单插件目录，不要将整个 WhaleBot 仓库当作单插件安装。

无第三方 Python 依赖。数据文件为：

```text
/AstrBot/data/plugin_data/astrbot_plugin_directional_memory/memories.sqlite3
```

## WebUI 配置

进入 **插件 → 单向个人记忆 → 配置**。正常保存配置时 AstrBot 会重载插件，配置随之生效。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关 |
| `allowed_user_ids` | `[]` | 真实用户 ID；空列表允许所有人分别使用自己的记忆。试用建议仅填主人 QQ |
| `capture_group_messages` | `true` | 自动记录用户自己的群聊文字 |
| `capture_private_messages` | `true` | 自动记录私聊文字；关闭仅停止新增，不删除旧记录 |
| `inject_in_private` | `true` | 私聊汇总本人的各来源 |
| `inject_in_group` | `true` | 群聊仅注入本人本群记录 |
| `min_message_chars` | `4` | 自动记录最短长度，范围 1–100 |
| `max_source_chars` | `1200` | 每条文字保存上限，范围 100–4000；超长文本截断 |
| `retention_days` | `180` | 保留天数，范围 1–3650；过期记录不召回，后续写入时清理 |
| `max_records_per_user` | `1000` | 同平台、同机器人、同用户合计记录数，范围 10–10000，超限移除最旧记录 |
| `recall_limit` | `5` | 单次最多召回 1–20 条 |
| `max_inject_chars` | `1200` | 单次总注入字符预算，范围 300–6000，包含来源标签和头尾 |
| `skip_sensitive_messages` | `true` | 跳过明显含密码、密钥等格式的文字；不保证识别所有敏感信息 |

自动记录开关只控制被动采集；`remember` 是本人明确要求保存的操作，仍可使用。注入开关只控制自动加入模型请求，`recall` 是本人显式查询。总开关与启用名单则适用于全部入口。

## 命令

| 命令 | 行为 |
| --- | --- |
| `/dmem` 或 `/dmem status` | 查看当前作用域及帮助，不展示全局人数或他人统计 |
| `/dmem remember 我喜欢简短的回答` | 将本人的文字保存为当前来源的明确备注 |
| `/dmem recall 喜欢` | 查询当前身份和场景允许的记录 |
| `/dmem forget` | 显示本次删除范围与确认方式 |
| `/dmem forget CONFIRM` | 群聊仅删除本人本群记录；私聊删除本人在该平台该机器人下的全部来源记录 |

这里的删除仅影响本插件，不影响 AstrBot 对话历史或 LivingMemory。没有跨用户查看/删除命令，管理员也不能借这些命令读取其他人的记录。

## 与现有插件共存

- **LivingMemory**：继续保持 `memory_scope_mode=legacy`、`use_session_filtering=true`；不要改成 `global` 或跨群用户桶。它可保留当前会话原有记忆，本插件提供单向汇总。
- **chat_plus**：使用其保留的临时内容块接口，不改变回复概率、群等待窗口或并发策略。
- **self-learning**：继续保留现有风格学习与 LivingMemory 委托，不增加第二套自动回复策略。

不会自动导入 LivingMemory 旧摘要。旧摘要可能混合多人发言，不能只因包含某个人名就认定整段都属于这个人。日后导入必须验证真实用户和来源；来源不明的记录应跳过。

本插件的事实记忆按用户而非人格隔离：同一平台、同一机器人账号、同一用户切换人格时，事实记录仍相同。不同机器人账号或不同平台不会自动合并。启用名单只认真实 ID，不做昵称合并。

人格由 AstrBot 当前会话的自定义规则决定。主人在群内也使用该群指定的人格，私聊人格只用于私聊。本插件不写入人格 ID、人格规则、系统提示词或会话绑定，记忆中的角色、关系和语气指令不能替代当前人格。

开启 `unique_session`（群内按用户隔离）时，群内会话 ID 包含 `用户ID_群号`。此版本 AstrBot 的人格规则按完整会话 ID 精确读取：仅绑定 `GroupMessage:群号` 不会自动覆盖 `GroupMessage:用户ID_群号`，需为实际会话设置对应人格。不要为了继承群人格而把私聊与群聊合并。

## 验收

用两个群、两个账号分别测试，使用虚构且无敏感性的标记：

1. 用户甲在 A 群 `/dmem remember A-测试标记`，在 B 群保存 `B-测试标记`，私聊保存 `P-测试标记`。
2. 用户甲私聊 `/dmem recall` 能看见三种来源。
3. 用户甲在 A 群只能看见 A，在 B 群只能看见 B。
4. 用户乙在相同群或私聊看不见甲的标记。
5. 在 A 群执行 `forget CONFIRM` 后，B 和私聊的标记仍存在。

测试不要求发送真实私密内容。单元测试使用临时 SQLite 数据库和模拟事件，不访问部署数据：

```text
python -m unittest discover -s plugins/astrbot_plugin_directional_memory/tests -v
```

真实 AstrBot API 的额外验收脚本为 `tests/runtime_smoke.py`，需在 AstrBot 环境下单独运行：

```text
PYTHONPATH=/AstrBot python -B /path/to/astrbot_plugin_directional_memory/tests/runtime_smoke.py
```

它只构造虚构事件，使用临时数据库并模拟会话权限查询，不发送 QQ 消息。AstrBot 4.29.3 验收包含单元测试和 50 项真实 API 检查。

## 成本、边界与回滚

本插件不增加模型或向量 API 调用，但加入上下文的文字仍消耗模型输入 Token。字符预算不是 Token 硬上限。

SQLite 保存可读原文，需保护 Docker 数据卷和备份；启用名单不是数据库加密。私聊可以汇总本人群聊经历，但不应把群聊中其他人的完整发言或秘密当成本人的记忆导入。

本插件约束自己的存储、命令和注入，不会替其他插件、已有会话历史或用户手工粘贴的内容建立权限边界。不要同时开启其他插件的全局共享或私聊→群聊功能。规则识别凭据只是辅助，不能代替谨慎处理敏感数据。

简单回退可在 WebUI 停用本插件，现有 AstrBot、LivingMemory 和聊天策略不变；新数据库保留供备份。完整环境回滚点见仓库 `backups/pre-directional-memory-20261028-231331/ROLLBACK.md`（仅本机存在，含私人数据，不提交）。
